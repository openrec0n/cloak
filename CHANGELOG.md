## [0.1.0] - 2025-02-04

### Added
- Initial public release
- AWS security assessment techniques for S3, IAM, EC2, Lambda, and STS
- Privacy-first architecture: sensitive data stored locally, never enters AI context
- Dry-run mode by default with explicit execution flag
- Claude Code integration with skills and hooks
- SQLite storage for execution history and results
